# Neneca — O Espetáculo

Site estático para GitHub Pages.

## Estrutura
- `index.html` — página principal
- `assets/images/` — fotos
- `assets/music/` — músicas da rádio
- `assets/video/` — vídeo
- `.nojekyll` — arquivo auxiliar para GitHub Pages

## Publicação
1. Crie um repositório no GitHub.
2. Envie `index.html` e `.nojekyll` para a raiz.
3. Crie a pasta `assets` e envie suas subpastas/arquivos mantendo exatamente os nomes.
4. Em Settings → Pages, escolha `Deploy from a branch`, branch `main` e pasta `/ (root)`.

Não renomeie as pastas nem os arquivos dentro de `assets`, porque o `index.html` já aponta para esses caminhos.
